# Miki-Rhino 0.2 and desktop integrations implementation plan

> **For agentic workers:** Use superpowers:executing-plans. Track each release gate separately.

**Goal:** Stabilize Rhino's MCP connection, make document inspection available in Codex and DSH, and submit independently verifiable packages.

**Architecture:** Keep the Rhino 9 plugin and exact geometry kernel. Share a dependency-free localhost adapter between the Codex stdio server and DSH's native tool registration. Use the existing GitHub Actions Windows package for the public Rhino build.

**Tech stack:** C#/.NET 8, Rhino 9 Windows, Node.js 22+, JSON-RPC, DSH Cordis.

No model-service credentials are needed by the desktop bridge. The configured Rhino MCP listener must be loopback-only. Text results may contain document metadata that the selected host sends to its model; use a test document for demonstrations.
